# Studio Izlu

Site institucional de estudo para um estúdio de estética automotiva, com planos de serviço e contato via Instagram.

![Logo](img/logo.png)

## O que foi praticado

- HTML e CSS com **Bootstrap 5** e Bootstrap Icons
- Seções de planos (bronze, prata e ouro), diferenciais e contato
- Fonte Sora (Google Fonts) e imagens em WebP

## Como abrir

Abra o `index.html` no navegador.
